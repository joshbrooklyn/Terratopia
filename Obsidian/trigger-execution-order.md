When effects in combat trigger, they happen in this order:
1. Run Modifiers
2. Dungeon Modifiers
3. Fight/Room Modifiers
4. Character Specializations
	1. In Party Order first to last, then in order they were equipped
5. Adventurer Perks
	1. Same order
6. Adventurer Boons/Curses
7. Adventurer Gear
8. Enemy Traits
	1. Left to right, top to bottom how they appear in the UI
